## 概要

STP（Segmentation / Targeting / Positioning）フレームワークを整理し、ペルソナ設計と画面設計をビジネス目的に接続できるようにする。

---

## 学習順序

### ステップ1：STPの全体像を掴む（1時間）

まず「STPはターゲットを絞るための3段階の意思決定プロセス」と理解する。

**読む順序（合計30〜40分）：**

1. [Salesforce: STP分析とは？](https://www.salesforce.com/jp/blog/jp-stp-analysis/) — S / T / P の定義と流れ（無料・日本語）
2. 『[USJを劇的に変えた、たった1つの考え方](https://www.kadokawa.co.jp/product/321512000336/)』の序章〜第2章 — 「消費者視点」「WHO / WHAT / HOW」で STP を実務に接続する

STP の3段階：

1. **Segmentation**：市場を何らかの軸で分けて地図を作る
2. **Targeting**：その中でどのセグメントを狙うかを選ぶ
3. **Positioning**：選んだセグメントの中で「どう見られたいか」を決める

Segmentation の3軸を覚える：

- デモグラフィック（年齢・性別・職業・収入）
- サイコグラフィック（価値観・ライフスタイル・課題意識）
- 行動（購買頻度・利用シーン・得たいベネフィット）

残り20分は、上記3軸を自分の言葉で1行ずつメモする。

### ステップ2：実在サービスのSTPを逆算する（1時間）

**Notion を題材にして分析する**（自分がユーザーとして実感があるため）。

- Segmentation：「情報管理に課題を感じているナレッジワーカー」層を特定
- Targeting：なぜ「エンジニア・デザイナー・スタートアップ」から攻めたか
- Positioning：「All-in-one workspace」というコピーが意味すること

上記をドキュメントにまとめると、「STPがUIの言葉・機能・デザインにどう反映されているか」が見えてくる。

### ステップ3：パーセプションマップを作る（30分）

Notion を中心に、Confluence / Obsidian / Google Drive などを同じ図に置く。

- X軸：個人向け ← → チーム向け
- Y軸：シンプル ← → 高機能

競合がいない「白地」を探すことが Positioning の目的。この図は後の Issue #7（LP改善）でも使える。

### ステップ4：ペルソナシートを1枚作る（30分）

STPの Targeting から逆算して、「このセグメントを代表する1人」を具体化する。

| 項目 | 記入内容 |
| --- | --- |
| 名前・年齢・職業 | 架空で良い |
| 課題 | 何に困っているか |
| ゴール | 何を達成したいか |
| よく使うサービス | 行動の背景を理解するため |
| 行動パターン | いつ・どこで・どのように使うか |

### ステップ5：ペルソナと画面設計を接続する（30分）

Issue #2（Fogg BM）の知識を使って接続する。

- 「このペルソナは時間的 Ability が低い（忙しいエンジニア）」→ 最初のアクションを極限まで減らす
- 「このペルソナは損失回避が強い」→ 「無料で試せる」「カード不要」を前面に出す
